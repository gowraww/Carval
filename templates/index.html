About CARVAL

CARVAL is a Machine Learning-based used car price prediction application. It uses vehicle information such as brand, model, manufacturing year, mileage, engine capacity, fuel type and kilometers driven to estimate a car's selling price. The application uses a trained Linear Regression model integrated with Python and Flask.
